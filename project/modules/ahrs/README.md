# AHRS 模块

基于扩展卡尔曼滤波（EKF）的姿态解算模块，BMI088 六轴 IMU，可选 IST8310 磁力计融合。
C板专属模块，对非C板项目无移植性

## 依赖关系

```
DWT (bsp_dwt)  ← 必须最先初始化
  ↑
BMI088 (SPI)
  ↑
AHRS (姿态解算)
  ↑
应用层 (云台/底盘控制)
```

**关键规则**：
1. `DWT_Init()` 必须在 `AHRS_Register()` 之前调用
2. `Robot_Init()` 中的初始化顺序：`DWT_Init()` → `Remote_Init()` → `AHRS_Register()`

## 坐标系定义

### 机体坐标系 (Body Frame)

默认正方向（以 PCB 上 "R" 字为参考）：

```
        X (前)
        ↑
        |
  Y ←───┼───
 (左)   |
       Z (上，出纸面)
```

- **X 轴**：R 字上方方向（前）
- **Y 轴**：R 字左方方向（左）
- **Z 轴**：垂直板面向上
- 右手定则：拇指指向轴正方向，四指弯曲为正旋转方向

### 旋转方向约定

| 运动 | 陀螺仪符号 | 欧拉角变化 |
|------|-----------|-----------|
| 板子右倾（右低左高） | gyro_x > 0 | roll 增加 |
| 板子低头（前低后高） | gyro_y > 0 | pitch 增加 |
| 水平逆时针旋转（俯视） | gyro_z > 0 | yaw 增加 |

### 世界坐标系 (Navigation Frame)

- X：机体正前方
- Y：机体正左方
- Z：垂直向上（重力方向 `[0, 0, 1]`）
- 欧拉角：ZYX 顺序分解

### 欧拉角输出

`euler[0]` = roll（横滚，绕 X 轴）
`euler[1]` = pitch（俯仰，绕 Y 轴）
`euler[2]` = yaw（偏航，绕 Z 轴）
`yaw_total` = 累计偏航角（处理 ±180° 跳变，单位 deg）

## 安装角补偿

### 背景

板子装在云台上时，可能不是完全水平的（有安装偏差）。安装角用于补偿这个偏差，让 AHRS 输出正确的姿态角。

**坐标轴定义（已验证）**：
- X 轴：板子前方（"R" 字上方）
- Y 轴：板子左方（"R" 字左方）
- Z 轴：垂直板面向上
- Roll：绕 X 轴旋转，正方向 = 右倾（右低左高）
- Pitch：绕 Y 轴旋转，正方向 = 低头（前低后高）
- Yaw：绕 Z 轴旋转，正方向 = 逆时针（俯视）

### 原理

`install_rot` 是一个 3×3 旋转矩阵，将传感器坐标系 (S) 的数据旋转到机体坐标系 (B)：

```
gyro_body = install_rot × gyro_sensor
accel_body = install_rot × accel_sensor
```

EKF 在机体坐标系内工作，输出四元数描述机体到世界坐标系的旋转。

### 输入方式

在 `AHRS_Init_Config_s` 中填入板子相对云台的姿态角（单位：度）：

```c
AHRS_Init_Config_s config = {
    .board_yaw   = 0.0f,  // 板子偏航角 [deg]（正值=板子逆时针转）
    .board_pitch = 0.0f,  // 板子俯仰角 [deg]（正值=板子低头）
    .board_roll  = 0.0f,  // 板子横滚角 [deg]（正值=板子右倾）
};
```

内部自动取反构建旋转矩阵，让 AHRS 输出归零。

旋转矩阵由 ZYX 欧拉角构建（先 yaw → 再 pitch → 再 roll）。

### 如何确定安装角

**规则：填入板子相对于云台的实际姿态角（正值），内部自动取反补偿**

| 板子实际姿态 | config 设置 |
|-------------|-----------|
| 板子左转 90° | board_yaw = 90° |
| 板子前倾 30° | board_pitch = 30° |
| 板子右倾 45° | board_roll = 45° |

**实验法**（最可靠）：
1. config 全设 0，烧录
2. 板子装上云台，调到你认为"水平"的位置
3. 在 Ozone 中查看 euler 输出：比如 roll=5°, pitch=-3°
4. 设置 board_roll=5°, board_pitch=-3°（直接填观察到的值）
5. 重新烧录验证：euler 应该接近 roll≈0°, pitch≈0°

注意：yaw 只影响航向起点，不影响 roll/pitch 精度。水平放置时 yaw 无法确定（万向锁），设 0 即可。

### 常见安装方式参考

以下为板子相对于云台的安装角度（已验证）：

| 板子安装方式 | board_yaw | board_pitch | board_roll |
|---|---|---|---|
| 正常水平安装 | 0 | 0 | 0 |
| 板子左转 90° 安装 | 90 | 0 | 0 |
| 板子前倾 45° 安装 | 0 | 45 | 0 |
| 板子右倾 30° 安装 | 0 | 0 | 30 |

## EKF 配置参数

### 状态向量

- 无磁力计：`x = [q0, q1, q2, q3, bx, by]`（6 维）
- 有磁力计：`x = [q0, q1, q2, q3, bx, by, bz]`（7 维）

### 过程噪声 Q

| 状态 | Q 值 | 说明 |
|------|------|------|
| q0-q3 | 10 × dt | 四元数过程噪声，对齐旧代码 Q1=10 |
| bx, by | 0.001 × dt | 陀螺仪零偏随机游走，对齐旧代码 Q2=0.001 |

### 观测噪声 R

加速度计 R = 1,000,000（对齐旧代码，高 R 表示强信任预测、弱修正观测）

### 初始协方差 P

对角线：`[100000, 100000, 100000, 100000, 100, 100]`
四元数初始不确定度大（快速收敛），偏置不确定度中等。

### 渐消因子 lambda

默认 0.9996。对 P 矩阵施加衰减，防止过度收敛。

## 数据流

```
BMI088 → 原始数据 (sensor frame)
  ↓
install_rot 旋转 → 机体坐标系数据
  ↓
减去零偏 → 去偏陀螺仪数据
  ↓
EKF 预测 (F 矩阵 + 陀螺积分) → 先验四元数
  ↓
EKF 更新 (加速度计观测 → 修正四元数 + 估计零偏)
  ↓
四元数归一化 → 欧拉角输出
```

## 回调函数

- `AHRS_Predict_Callback`：计算 F 矩阵（6×6 或 7×7）
  - 左上 4×4：四元数-角速度耦合（使用 bias 补偿后角速度）
  - 右上 4×2：四元数-零偏耦合（使用四元数状态）
  - 右下 2×2：单位阵（零偏随机游走）
- `AHRS_Update_Accel_Callback`：计算 H 矩阵和 h(x)
  - h(x) = R(q)^T × [0, 0, 1]（预测的归一化重力方向）
  - H = ∂h/∂x（3×6 Jacobian，偏置列全零）

## 宏开关

- `AHRS_USE_MAGNETOMETER`：启用磁力计融合（状态扩展到 7 维）
- `AHRS_DISABLE_RTOS`：禁用 RTOS，改为裸机模式（需外部调用 `AHRS_Task()`）
